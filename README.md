## 🚀 Featured projects

An AI-assisted data engineering project bringing together warehouse development, data transformations and CI/CD workflows.

### 🤖 [Agentic AI Data Agent](https://github.com/Rizvi-07/agentic-ai-data-agent)

A multi-agent system that routes natural-language requests to specialized SQL and ETL agents.

- Uses a main agent to identify intent and delegate tasks.
- Supports database queries and data extraction and transformation workflows.
- Combines LangGraph orchestration, tool-based execution and SQL safety validation.

**Technologies:** Python 路 SQL 路 LangGraph 路 LLMs 路 AI Agents

An interactive HR dashboard covering workforce demographics, growth and location insights.

- Built DAX measures for tenure analysis and workforce trends and optimized data models.
- Applied Power Query transformations and data aggregation to prepare HR data for reporting.
- Implemented role-based security to manage access to dashboard insights.

**Technologies:** Power BI 路 MySQL 路 DAX 路 Power Query

### 📚 [BulkyBook](https://github.com/Rizvi-07/BulkyBook)

An e-commerce book platform built with ASP.NET Core Razor Pages and Entity Framework Core.

- Implements user authentication and role-based access control.
- Uses dependency injection and repository patterns to structure the application.
- Connects a Bootstrap and jQuery interface to a SQL Server database.

**Technologies:** ASP.NET Core (.NET 8, C# 12) 路 EF Core 路 SQL Server 路 ASP.NET Core Identity 路 Bootstrap 路 jQuery

### 🖥️ [WPF Personal Tracking System](https://github.com/Rizvi-07/WPF_Personal-_Tracking)

A role-based desktop HR system built with WPF and Entity Framework Core.

- Implements Employee, Task, Leave and Salary modules with SQL schemas and CRUD operations.

**Technologies:** WPF 路 .NET Core 路 EF Core 路 SQL Server
